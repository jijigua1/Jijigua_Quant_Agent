# 开源候选工程审计

> 2026-10-15最终更新：所有者已批准公开范围、自有代码权利及AGPL-3.0-only（版权jijigua1）。下方保留审阅时的过程记录；当前决定以`provenance/OWNER_APPROVAL.json`、根LICENSE和最终manifest为准。远端CI结果需另行实际核验。
本仓库将自然语言和论文主张转成受控因子研究及版本报告。审查按单人/少量前台研究的实际负载判断；不把它当作已加固多租户SaaS。以下检查在独立副本进行，不修改生产或活跃研发。

## 必须保留的发布门禁

1. **项目及本地工具包许可尚未选定**（`provenance/RIGHTS_REVIEW.json`）。源码存在和AI辅助开发不自动提供统一许可；完整PDF功能还涉及PyMuPDF AGPL。处理：所有者选择兼容许可并确认自有代码范围。跳过会产生无权分发或错误授权。
2. **候选Python审核不是沙箱**（`src/paper_agent/registry.py::_load_module`）。人工精确SHA批准后源码在非root Agent进程执行。处理：公开文档明确威胁边界，不宣称可安全运行恶意代码。真正敌对多租户服务仍需独立执行隔离。
3. **旧依赖命中已知公告**（`provenance/DEPENDENCY_VULNERABILITIES.json`）。历史环境可复现不代表新安装安全。处理：保留历史记录，在公开副本升级受影响依赖并用OSV、干净venv及回归复核；不改生产。原始公告匹配不是具体可利用性结论。
4. **真实论文回放和外部函数未取得再分发许可**。处理：从公开树隔离，明确skip；传输测试改用原创PDF，格式测试用原创探针。不能以这些测试代替最新真实论文/原消费者验收。

## 应继续追踪的工程风险

5. **历史部署脚本具有环境耦合及cron副作用**（`deploy/rollback_production_v1.sh`）。回滚Agent可能连带停止数据更新。公开只作为审阅模板，不能引导用户盲目root执行；生产修复不在本轮范围。
6. **缓存与语义升级需持续治理**（`rolling_test`与`paper_research/factor_ir.py`）。当前有IR语义版本，但不是所有执行器实现SHA迁移都已完成。定义/数据/合同改变时必须新版本，旧签名不改。
7. **用户入口与研究版本仍需环境验收**。历史read_study曾产生评价副作用，最新副本已有read/refresh分离；源码存在不能证明生产已升级。公开状态表分别列出生产和预发布。
8. **前台进程取消不是持久任务系统**。本地SSH退出后可能有远程孤儿进程；运行锁是协调措施，不是完整进程隔离。不得以Ctrl+C退出码证明整树停止。
9. **数据质量不支持正式账户业绩**。未复权、PIT与交易状态缺口仍在；Sharpe/NAV/费用应保持不可用，不能靠漂亮报告补足。
10. **跨平台验收范围有限**。Windows新venv实测；Linux/macOS本轮没有真机执行，Actions也尚未发布运行。不能把使用文档当作兼容性证据。

- 两个旧断言不适配新版14图和三阶段核心表：保留原失败证据，更新后要求精确图集合、文件存在、图像计数及Test空值，不降低数值或授权断言。
- 移除未许可原消费者/账本，保留隔离记录与SHA；不把原创探针叫“原程序验收”。
- 新增公开凭据/文件/链接/语法/Git历史门禁、依赖公告查询及失败分支测试。
