# 归档自身的转换与失败记录

原活跃项目、生产、candidate4和v1rc未被本轮修改。公开候选保持Python包路径；下列是归档副本的修改，不冒充内部原始版本。

| 变动 | 原因与边界 | 验证 |
|---|---|---|
| 私有路径/主机/操作员标记模板化 | 不公开实例定位、凭据及个人资料；旧工程记录含义保留 | 模式扫描、人工位置复核、双SHA |
| Skill Markdown字节恢复 | 归档文档换行归一化曾导致29项Skill哈希拒绝 | 恢复来源字节，批准清单逐项校验；不改授权SHA绕过 |
| `.gitattributes`禁自动文字转换 | Skill/工具源码内容指纹是运行合同，CRLF→LF会让clone不可运行 | 新Git历史及真实本地clone字节核验 |
| 原Gyc/Perry函数与Pyx摘录隔离 | 外部作者再分发许可不明 | 原始SHA保留，不发布原实现 |
| 原创格式探针修复columns.name | 首次原创替代漏元数据，完整轮次1项失败 | 保留失败；修根因后原断言通过 |
| 老报告测试合同适配 | 实现已14图/三阶段，测试仍7图/2阶段 | 精确图集合/计数/空Test行，不降数值断言 |
| `/srv/`路径不折行 | 公开路径模板化后长路径复制被折行 | 终端相关测试通过 |
| 缺版权输入回放跳过 | 不使用真实论文全文、模型重放来凑公开通过率 | 跳过数明确列示；原创PDF只验证运输 |
| 安全pins及可选paper依赖 | 原复现锁命中公开公告 | 保留原锁；OSV+干净venv及回归 |
| 合成样例与原创论文 | 提供不需要Key/真实行情的可运行入口 | 独立因子/指标复算，真实浏览器QA |
| 公开样例使用OFL字体 | 原机器自动选中的字体许可未一并归档 | 使用已核实Noto OFL仅重渲染；表格JSON相等 |

字体重渲染预演曾因外部PKL的字符串日期轴、重复创建报告版本索引而停止；仅在新的合成副本修正调用前提后生成，不修改研究算法，不覆盖原产物或真实账本。它不是生产缺陷结论。

没有迁移真实账本/数据，没有追加真实研究/API请求，没有把某个预发布文件混进冻结源快照。最终每文件原/最终SHA和来源在公开来源清单记录。
