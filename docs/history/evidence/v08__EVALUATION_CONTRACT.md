## 统计口径

| 内容 | 口径与保存证据 |
|---|---|
| IC / RankIC | 共同有效股票的Pearson / 平均秩Spearman；每日结果保存 evaluation_daily.csv |
| IR | 均值/样本标准差(ddof=1)，不年化；零方差N/A |
| 年/月 | 从真实逐日序列分别聚合；有效评价日、共同股票数和完整股票轴覆盖率各自保留 |
| HAC | Bartlett/Newey-West；B=max(H−1,floor(4(n/100)^(2/9)))；至少60日及10(B+1)日；渐近正态双侧p和95%区间 |
| 缺失推断 | 只裁结构性首尾NaN；内部缺失不压缩成连续交易日，返回insufficient；常数序列unsupported |
| 短月份 | 描述性统计；不以通常20日的样本宣称显著，不打印显著性星号 |
| 分组 | G0为高分，G0−末组；未来毛收益及其累计算术和，重叠标签，均非账户NAV |
| 自相关 | 共同可观测股票的相邻/滞后截面相关，再按时间汇总；值/秩相关与交易换手不同 |
| 稳定性 | 分区内20/60观察日完整窗口滚动相关；累计相关按分区重置；年度方向、正月份比例及连续非正月份 |
| 敏感性 | 预先固定MAD robust-z>5移除诊断；MAD=0不擅自移除；不用于自动选择新因子 |
| 显著性限制 | 观察日网格尚非认证交易所日历；渐近区间不是有限样本精确t检验，未校正多次试验/选参偏差 |

年度、月度、分区、极端日期、价格/成交量区间覆盖、敏感性分别保存CSV；热力图和交互图保存原始JSON。所有结果纳入manifest SHA-256。

## 研究判断

Research Verdict基于冻结的高分看多方向、有效日、HAC区间、年度方向一致性、覆盖、正月份及分组证据；不是单一IC阈值。n≥60、年度方向支持≥60%、覆盖≥50%等准入规则显式披露。负方向不事后翻转以宣称成功；Validation已曝光，所有状态均tradable=false。

缺少PIT行业/市值/参考因子时不计算相关扩展。参数扰动不自动对Validation择优。无账户回测准入，不输出账户Sharpe、成本或净值回撤。

## Test合同

每份报告从创建时就含Train(2020—2023)、Validation(2024—2025)、Test(2026认证实际范围)。首页、核心表、年度表、月度热力图、稳定性和Verdict保留三个阶段。NOT_RUN必须为SEALED，不能携带Test数值；2026热力图为空N/A，不能把未评价样本数填0。

独立结果必须标明评估类型、定义/数据/代码指纹与曝光，由CONTROLLED_EVALUATOR输出。操作者验证签名、冻结表达式/标准化/预测期/分组数、原study_id及源指纹后才允许生成report_revision=2。合并后的年度/月度CSV、热力图与趋势用同一合法结果；日度结果仅为聚合IC/RankIC/覆盖率，不含股票价格或收益标签。

版本报告放在授权成果根下独立report_revision目录，通过原研究目录reports/report_versions.json关联同一study_id。原PKL、HTML、Markdown、计算配置和任务记录不覆盖；自然语言读取可返回最新合法报告，旧task/result仍保留历史证据。模型工具没有合并入口和签署密钥。真实签名接收通道、身份及私有快照仍需独立审批；不能手工把模型JSON当成合法Test证据。

参考方法：[statsmodels HAC covariance](https://www.statsmodels.org/stable/generated/statsmodels.stats.sandwich_covariance.cov_hac.html)。本实现通过独立密集Bartlett二次型交叉核对，不依赖statsmodels运行时。
