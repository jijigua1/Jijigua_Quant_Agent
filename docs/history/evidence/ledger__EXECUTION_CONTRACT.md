# Phase 3-B1 候选执行合同（合成验收版）

版本：`qra-execution-candidate/0.1`。此合同区分“本轮验证”“规定但未实现/未验证”，不授予正式回测资格。

| 项目 | 固定合同 | 本轮状态 |
|---|---|---|
| 信号时点 | T 日收盘后才可使用 T 行 score、资格和已发布信息；禁止 T 收盘信号成交于 T 收盘/开盘 | `align_signal.shift(1)`、周五→周一和未来行扰动合成通过；真实数据可获得时间未证 |
| 下一执行时点 | 经版本化交易日历取 T 后首个交易日开盘；非交易日不产生虚构报价 | 合成 4 日历行通过；真实 CSI300/交易所日历未准入 |
| 价格 | 原始开盘价是观察报价；买成交价 `open×(1+slippage)`，卖成交价 `open×(1−slippage)`；非真实盘口成交证明 | 价格与滑点合成通过；市场冲击/队列/成交量未验 |
| 买卖能力 | 执行日独立 `can_buy/can_sell/suspended`；涨停拒买、跌停拒卖须由可信逐日状态给出，未知默认拒绝 | 用合成 mask 验证拒单与后续处理；真实 mask 在 Phase 3-A 不合格 |
| 订单 | 信号生成候选目标；卖单先于买单；不足一手、现金不足、不可交易均拒单并记录；拒单不自动补选 | 成交/事件通过；完整委托数量与状态尚缺 |
| 续持与资金 | 到期卖不出则持仓、占槽继续；被拒买的配额留在槽位现金；无透支 | 合成通过；没有券商级预冻结与释放流水 |
| 股数与整手 | raw 模式采用实际股数；常规沪深买入 100 股整数倍、科创板初始 200 股；卖出允许零股清仓仅在经过交易规则审查后 | 常规 100 股与不足一手通过；板块/历史规则及送股零股未完整实现 |
| 费用 | 应分列佣金、最低佣金、卖出印花税、交易所费用及滑点；买卖侧分别扣实际成交额 | 最低费、打包卖出费率、滑点单项通过；最低佣金+印花税并存 **失败/P1** |
| 公司行动 | 只接受独立来源的生效日、持有人资格、净现金/股、股数倍率和税口径；开盘前处理，事件不等同 adj_factor | 整倍送股+现金分红合成通过；实际来源/到账/零股/配股未验证 |
| 估值 | 期末资产=`cash+Σ(实际股数×有效估值价)`；仅有已证明停牌时可携前值且标 stale；未知缺价应失败，不得填零收益 | 正常/停牌携前值/未知缺价阻断通过；退市清偿与长期停牌估值未定义 |
| 净值与收益 | 日 NAV 使用执行后现金与持仓；`期初资产+价格经济收益+分红−费用−滑点损耗=期末净资产`，不能把分组毛收益当账户收益 | 手算 oracle 及逐日现金、持仓、市值、NAV 核对通过 |
| 可追溯性 | 输入/策略/规则/日历/代码版本和 SHA、信号、目标、委托、成交、拒单、成本、公司行动、日账一一关联 | 本轮源 SHA、合成信号/目标/成交/事件/账本存档；拒单缺申请数量，尚非完整订单轨迹 |

**数据和模型隔离。** 未来主 Agent 只可见独立发布的 Train/Validation 研究资源，不可见含 Holdout 的原始完整 PKL、底层 FD、缓存、目标收益或逐日测试表现。Train 尾端以 `i+执行延迟+持有期+embargo < 分区交易日数` 清除未成熟标签；Validation 被查看后再次调参须记为已用验证集。Holdout 由独立身份、冻结实验哈希、受限次数和审计评估，不能用来调引擎或模型。当前 Phase 3-A `SplitReader` 只是原型，**服务器物理隔离未实现**；本轮仅用合成日期测试边界。

任何合同项缺数据、缺执行规则或出现不守恒时返回 BLOCKED/FAILED；不能静默改用 `adjusted_units`、默认全可交易 mask、零收益或模型解释来补全。
