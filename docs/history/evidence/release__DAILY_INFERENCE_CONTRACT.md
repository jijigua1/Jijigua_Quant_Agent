# 每日推理数据合同

每日最新信号与历史最终测试是两条不同通道。只在收盘后的数据更新完成、六字段同批质量检查通过、可信可得时间不晚于决策时间后，才产生 `asof` 版本。`daily_inference()` 本地原型要求冻结模型/因子 SHA、`asof` 晚于当前封存测试截止日、1–120 日暖机，返回仅供**受控计算进程内部**使用的原始输入切片；它不是 Agent Tool，也不能把该 `Panel` 直接交给模型。

计划中的独立 Daily Worker 读取受控最新输入，运行已经冻结的表达式或模型，向研究 Agent 只发布：`asof`、源批次、因子/模型 SHA、信号摘要、已公开日期标记、不可用原因。不发布 2026 历史收益标签、IC、回测绩效或整段暖机原始矩阵。若每日行情晚到、六文件混版、上市日期未知或关键字段缺失，状态为 `NOT_READY`，不沿用旧信号冒充今日结果。

2026 年既被暂定为历史 Holdout 又包含日常已公开行情。任何向研究流程披露的最新日期及由其衍生的可用于选参信息，都记入 `exposure_ledger`；被看到的日期不再是严格盲测。冻结策略仅能用于推理，Daily 通道不得触发训练/参数搜索。若要滚动训练或改变 Holdout 截止边界，必须发布新分区和新研究协议，不在本轮自动进行。

本阶段只有输入检查函数与合成测试，没有实际日更数据发布、Worker、信号结果或主 Agent 集成。`/hy-tmp` 可能被清理，发布版本须另存持久备份后才能承诺可复现。
