# Phase 3-A 数据质量与风险报告

审计范围：`daily_update` 宽表 2019-01-02—2026-10-09（1,882 日、5,427 代码）及 Perry EOD/近期 CSV 的已有只读核验。核验程序与原始 JSON 均保存在 `survey/`，本次不运行全量服务器扫描。严重度代表对**该用途**的影响，不等于源文件损坏。

## 通过的基础检查

- 宽表日期唯一、有序，2019-01-02—2026-10-09 与 SSE/SZSE 日历在该区间 1,882 日一致；先前通用检查对 `Int64Index` 的解码失败由单独 `calendar_check.json` 复核补足。
- 8,675,338 个有效 close 单元中，OHLC 范围、价量同时存在与单位公式检查通过。`amount×10/volume` 均处于日低高价内。
- 2020-01-02—2026-10-09 的 8 字段实际静态解码和适配器读入完成；文件大小/哈希验证、越界/预算/未来字段/回测用途拒绝在 `real_sample_run.json` 中有记录。

## 影响认证的缺陷

| 问题 | 证据与范围 | 严重度 / 后果 | 当前处理 |
|---|---|---|---|
| 上市前价格回填或上市日期错配 | `real_sample_run.json`：2020+ 共 1,228 个早于 `TRD_Co` 上市日的数据单元；`pit_checks.json` 举出 `001914.SZ`、`302132.SZ` 首个交易数据早于清单上市日 | 高：未来成分、上市年龄和因子横截面泄漏 | 研究时按独立可信上市日期屏蔽，缺失真值时剔除可疑股票；正式回测 BLOCKED |
| 固定股票轴不完整 | 宽表 5,427 只、无北交所；与 `TRD_Co.csv` 比至少 5 只 2026 上市股缺失，部分停市/退市样本保留但规则不完整 | 高：选股宇宙和生存偏差 | 只声明“此固定沪深轴上的探索性样本”，不得宣称全 A 股 |
| 复权历史变动 | 旧快照与当前版重叠 8,192,856 对，7,812,105 对变化，5,295 代码受影响；真实适配器对 2020+ 切片发现 6,956,785 历史值改写和 17,540 删除 | 高：复现/PIT 历史收益不稳 | 固定文件 SHA；旧新结果分开；复权列不认证正式回测 |
| 复权因子异常 | 2020+ 样本有 5 个实质下降、16,212 个细小跳变；近 57 日对交易所昨收核查有 7 个无对应事件的显著变化 | 高：公司行动与执行股数/现金不可推导 | 需要权威逐事件公司行动表；仅数值探索 |
| 状态字段尾部冻结 | `real_sample_run.json`：`is_valid_trading`、`is_valid_suspension`、`is_valid_list` 末尾各约 93 个交易日相同；`is_valid_not_st` 约 94 日 | 高：停牌、ST、上市资格错误 | 当前不暴露为研究白名单或正式回测状态 |
| 状态语义错误 | 冻结前 `is_valid_list=false` 仍有 close 224,592 单元；`is_valid_suspension=false` 仍有 close 293,798 单元；EOD `trade_status=false` 仍有 close 511,856 单元 | 高：该布尔值不能直接解释为可买卖/停牌 | 拒绝作为成交约束；审查真实交易所状态或可信生产链 |
| 涨跌停价不可信 | EOD 8,717,251 对中，13,079 对 close 高于记录的 `limit_up_price` | 高：拒单模型会错判 | 不接入正式回测 |
| 上游名称/行业时点 | 近期 ST 名称来自运行时 `stock_basic`，2026-09-07 前未回填；行业分类有前向填充；历史可获得时间缺失 | 中高：中性化与样本选择可能窥未来 | 待 PIT 数据合同；不宣称已认证 |
| 独立 `vwap` 停更 | 宽表独立 VWAP 更新止于约 2026-08-07 | 中：末段覆盖断裂 | 不用作全区间执行价 |
| 文件格式/内存边界 | 静态解码主字段通过；9.99 GB EOD 使用 `pickletools.genops`，其大字节 opcode 在 `Blob` 替换前已物化 | 高：EOD 骨架方式不保证内存硬上限 | EOD Agent 动态读取 **BLOCKED**，需真正流式有界解析/独立受限进程 |

生产源码快照同时存在“先 ffill 状态表”和“按目标日重算真实状态”的分支；**实际文件尾部冻结是已观测事实**，不能因为新版源码看似修复就判定历史文件可用。近期 CSV 的 ST、涨跌停有名称识别/板块比例等推导，不能替代交易所历史事件。Tushare 产生/发布时刻未逐日记录，`T` 行的历史决策可用时间仍属未验证。

**认证梯度。** 格式可读：主 8 字段通过；基础数值质量：六个原始价量字段在已核验区间通过；历史时点可信：部分通过/关键字段未证明；探索性因子研究：六字段是候选，需先发布独立 Train/Validation 快照；正式回测候选：不通过；正式回测准入：不通过。统计显著性、IC 与策略收益不在本次管理员式数据质量审计中计算，尤其不触碰 Holdout 表现。
