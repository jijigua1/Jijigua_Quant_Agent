# Train / Validation / Final Holdout 合同

以 Asia/Shanghai 交易日为准，含端点：Train `2020-01-01..2023-12-31`（旧版实际 970 日），Validation `2024-01-01..2025-12-31`（485 日），Final Holdout `2026-01-01..2026-10-09`（旧版 183 日）。自然年端点不是交易日。更新测试截止日需要新合同和审批，不在本轮自动滑动。

| 用途 | 实际发布状态 | 可见范围 | 标签与决策边界 |
|---|---|---|---|
| Train | **未发布** | 未来独立只读六原始字段快照；不含 2024–2026 | T 收盘特征、未来执行和持有标签须在 Train 内成熟 |
| Validation | **未发布** | 未来独立只读六原始字段快照；不得回写训练 | 用于方案选择；每次查看记录曝光，之后不得称从未使用 |
| Final Holdout | **BLOCKED** | 研究进程无文件、FD、缓存、指标、报告入口 | 仅未来独立评估器按冻结的代码/参数/数据版本有限次评估 |

Phase 3-A `SplitReader.eligible_signal_dates()` 保留作标签成熟检查：若信号索引 `i`、执行延迟 `L≥1`、持有 `H≥1`、embargo `E≥0`，必须满足 `i+L+H+E < 分区交易日数`；回看暖机只能用该时点以前可得输入。重叠标签的统计序列相关需在后续评价中单独处理。Train 尾端 purge，Validation 尾端亦然。样本内单元测试可以用合成“2026”日期，但不得读取真实 2026 目标收益、IC 或策略表现。

**系统级隔离验收前不开放**：`quantagent` 当前读不到 root 原始 `close.pkl`（本轮 Linux `test -r` 为否），但 Train/Validation 尚无独立实物，Holdout 尚无独立评估身份/入口；有 root SSH 权限的人仍可能直接看源文件，故严格人类盲测需操作纪律与审计。未来研究身份只挂/只读 Train、Validation；评估身份独享 Holdout；发布者与两者不同；检查所有 Tool、原始 FD、缓存、日志、报告、预计算因子/标签以及 DeepSeek 上下文的旁路。软件拒绝测试加 Linux UID 实际拒绝测试都通过，才称 Agent 侧隔离成立。

每次最终测试须先冻结策略表达式、代码 SHA、参数、执行合同及数据版本，记录授权人、时间、用途、次数、输出摘要；测试原始逐日表现不能流入规划/调参上下文。当前评估器未建立，Final Holdout 全面拒绝。
