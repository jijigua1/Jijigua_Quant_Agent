## 1. 改动

| 项目 | 之前 | 现在 |
| --- | --- | --- |
| 批量 | 一次只能上传一个文件 | 可以写多个文件、文件夹或通配符；cmd/PowerShell 不展开 `*`，由工具展开 |
| 出错 | — | 先检查全部文件，任何一个不合格就一个都不上传，并列出原因 |
| 去重 | 只在服务器按 SHA-256 去重 | 同一批里相同内容只发送一次；服务器去重不变 |
| 进度 | — | `[i/N]` 逐篇显示，单篇网络失败不影响其它篇，最后汇总成功和失败数 |
| “刚上传的论文” | 只说“说研究我刚上传的论文” | 明确写出它指的是哪个文件；`list` 在那一行标出 |
| 重复上传 | **缺陷**：服务器返回 duplicate，但不更新时间，“刚上传的论文”会指向另一篇 | 服务器记录 `last_uploaded_at`（首次上传时间保留），重复上传的那篇成为“刚上传的论文” |
| 存储风险 | 只在报告页脚 | `upload`、`list`、`status` 都提示：论文库在 `/srv/jijigua-quant-agent/v1beta/papers`（实例本地 NVMe 数据盘），释放/迁移/重置后不保证保留，请保留本地原件 |
| Git Bash | Git 的 `scp` 会把 `/hy-tmp/...` 改写成 `C:/Program Files/Git/...` | 优先使用 Windows 自带的 `System32\OpenSSH`；教程补充了已被改写的配置怎么修 |

批量时没有让“刚上传的论文”变成“请选择”，因为现有合同和测试都约定它指最后一篇（例如先后上传两篇时）。工具会在上传结束时说明它指哪一篇，并提示其余几篇用文件名或标题词指定。服务器启动器的参数个数是 root 侧固定的，本轮没有改启动器。
