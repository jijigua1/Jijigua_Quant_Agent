## 1. 现有流水线（从源码确认）

```
PDF → paper_research.ingest/extract（版面、段落、公式、表格、v0.3 规则抽取）
    → paper_agent.evidence（段落切分、BM25 检索、引文逐字定位）
    → paper_agent.understanding（DeepSeek 读选定段落 → JSON；本地核验引文与公式语法；对照 v0.3 窗口/聚合读法）
    → paper_agent.planner（符号映射、频率换算、替代项、硬阻断、DSL 编译 → route = dsl | new_algorithm）
    → 用户确认替代口径（定义 SHA 冻结）
    → dsl：主 Agent 19 算子 DSL 研究
      new_algorithm：DeepSeek 写 Python → AST 静态审核 → 用户批准该 SHA
                     → 独立真值测试 → 真实计算与可信 IR 逐格比对
    → 报告（Economic Rationale、G0–G4、HTML）
    → 2026 滚动 Test：评价器只用可信代码重算（DSL / 固定因子 / 可信 IR 执行器），从不运行模型代码
```

关键约束：**2026 Test 只能重算可信 IR 能表达的定义**。因此扩展可信算子，本质上是在扩展“生产中能完成三阶段评价的论文范围”；只能用 Python 表达的算法，Test 必须如实标为未评价。

## 2. 四项核心缺陷的根因

| 编号 | 现象 | 根因（代码位置） | 性质 |
| --- | --- | --- | --- |
| A | 1110.3383（RSI/EMA）、MACD 被阻断 | `factor_ir` 语法只有 ts_sum/mean/std/max/min、算术、log/exp/sqrt/sign、cs_rank/zscore；**没有** EMA/递归、逐元素 max/min、滚动 rank/corr/cov、连乘；`\max(a,b)` 无法解析 | 工程能力缺口 |
| B | AQR 把“过去 1/3/12 个月累计收益”执行成“滞后 1/3/12 个月的单月收益” | 公式语法用下标 `t-k` 同时承担“滞后”和模型自造的“回看期”两种含义；模型写了 `sign(r_{i,t-1})`，planner 把 r 当单期收益派生为 `C[t-21]/C[t-42]-1`；**没有任何检查**比对“符号原文含义（over the indicated lookback horizon）”与“公式中的时间用法”；冻结定义与代码一致性检查不能发现定义本身错了 | 科研正确性缺陷（最高优先级） |
| C | AQR 期货研究被直接用股票数据执行 | 资产识别只用正则扫描**符号含义**里的 option/futures 等词；AQR 写的是 “market i”，摘要和数据章节中的 futures/58 markets/asset classes 根本没被检查；未区分“非忠实替代”和“资产替代” | 科研正确性缺陷 |
| D | cond-mat 的 `m` 被映射为 other | 符号表只取模型给的含义与 data_field；没有“原文定义检索 → 映射必须有词汇证据 → 无证据即阻断并指明缺失”的机制；阻断提示只说 FIELD_NOT_AVAILABLE | 科研正确性缺陷 |

## 3. 能力矩阵（加固前 → 目标）

| 能力 | 加固前 | 目标与验收方式 |
| --- | --- | --- |
| EMA（span、Wilder/RMA、通达信 SMA(N,M)） | 无 | 可信 IR 算子：显式 α、初始化（首值 / SMA 种子）、**有限截断窗口 W**（保证 Train 与 Test 在同一历史长度下逐值一致，残余权重写入决策）；全窗口有限才出值；参考实现与向量化执行器交叉测试；手算样例 |
| MACD（DIF、DEA、柱，国内×2 与国外差异） | 无 | 由 EMA 组合表达；不同软件定义作为显式替代项展示 |
| 逐元素 max/min | 只在 DSL；IR 无 | IR `maximum/minimum`；`\max(a,b)` 语法 |
| 长窗口 rolling mean/sum/std/max/min | IR 已有（执行器向量化） | 保持；长窗口性能测试 |
| rolling rank / corr / cov / 连乘 | 无 | IR `ts_rank`、`ts_corr`、`ts_cov`、`ts_prod` |
| 收益、对数收益、累计收益、滞后收益 | 能写成比值，但**语义不可区分** | 结构化时间语义：单期收益@滞后k、累计收益[窗口n, 跳过s]、对数累计、滚动均值；由 IR 模式识别生成“时间轴说明”，并与原文线索比对 |
| 时间序列回归 / 统计 | 无 | 先做 beta = cov/var（可由 ts_cov 表达）；残差类算法走 Python 路线，Test 如实未评价 |
| 论文→定义一致性 | 只有引文逐字核验、窗口/聚合读法对照 | 新增：时间语义线索抽取（中英文，确定性）+ 冲突规则（回看 vs 滞后、累计 vs 单期、跳过期、频率单位）+ 独立“审查”模型调用（只判断、必须引原文）+ 有界纠错重读；无法证明一致即阻断 |
| 定义→代码一致性 | 冻结 IR 与 Python 逐格一致 | 保留；新增：独立语义求值器在构造的价格路径上计算各组件，对照执行 IR，并生成可供人工核对的数值样例 |
| 资产类型识别 | 符号含义正则 | 全文确定性线索评分（摘要/数据/方法/附录分节加权，含合约、展期、保证金、到期、行权价、隐含波动率、持仓量、中文术语）+ 模型 research_object（须引原文）；非股票默认阻断；只有用户明确要求“用A股股票做探索性替代”才允许，并在决策、报告、HTML 中显著标为非忠实复现 |
| 符号表 | 模型给 data_field | 每个符号须有原文定义；全文定义检索（where/denotes/其中/表示）；映射到行情字段必须有词汇证据；未定义或有歧义即阻断，并指明符号、已检索位置和所缺证据 |
| 多因子文档 | 有候选列表 | 保留；补中文研报多因子用例 |
| 研报 / 双栏 / 跨页 / 扫描件 | 部分 | 分层读取，异常类型逐项测试；不可靠时如实阻断 |
| 新 Python 算子 | 静态审核 + 人审 + 与 IR 逐格比对 | 保留；IR 无法表达时用程序生成的不变性测试（无未来、对齐、NaN 传播、零分母）+ 独立参考实现；Test 标为未评价并说明原因 |
| 恢复与重试 | JSON 修复、公式修复各有上限 | 增加语义纠错重读（≤2 次）、所有重试记入账本（原因、成本、次数） |
| 历史错误研究 | 无失效标记 | 只追加的失效登记；报告与对话显示“定义无效”，不改动原成果 |
| HTML | 经济逻辑、G0–G4 已整改 | 新增“论文定义核验”章节：原文定义与证据、执行公式、时间轴说明、差异与替代、核验结论；定义不可信时整份报告标为无效 |
