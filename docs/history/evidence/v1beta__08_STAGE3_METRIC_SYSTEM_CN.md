# 第三阶段：完整因子评价体系 · 预发布验收报告（2026-10-15）

**状态：`IMPLEMENTED / OFFLINE_TESTED / NUMERICALLY_VERIFIED`（合成数据 + 4 项真实研究离线重渲染）。生产未改动。**

## 1. 设计原则

- 新模块 `src/research_agent/metric_system.py` 只读取已保存的逐日结果：
  - Train/Validation 来自 `data/evaluation_daily.csv` 与 `data/group_returns_gross.csv`（既有 qrtk 评价产物）；
  - Test 来自滚动评价回执里的逐日行（`data/test_receipt.json`，受控评价身份算好的聚合统计）。
- 不读取因子值、行情或任何 2026 数据，不改评价器和已签名回执。滚动评价器引用的 `factor_evaluation._period` 保持不变，因此回执定义不变。
- 所有指标是逐日行的确定性函数，独立代码可以逐值复现（第 4 节）。

## 2. 指标

| 层级 | 指标 |
| --- | --- |
| IC / RankIC | 均值、样本标准差（ddof=1）、IR = 均值/标准差（未年化）、胜率（有效日中 >0 的占比）、HAC 标准误、t、双侧 p、95% 区间 |
| 样本 | 有效日（RankIC 有限的日期）、平均股票数（因子与成熟标签都存在）、覆盖率 |
| 分组 | G0…G4 各组均值、标准差、HAC t（G0 为当日因子值最高组）；G0−G4 的均值、标准差、胜率、HAC 标准误/t/p/区间 |
| 单调性 | 日度 −Spearman(组序号, 组收益) 的均值；以及期间各组均值的同一统计 |
| 策略指标 | 年化收益、年化波动、夏普、最大回撤、换手：全部显示 `N/A：尚无经过验收的连续策略收益序列`，不用重叠的理论分组收益代替 |

HAC 沿用既有合同：Bartlett Newey-West，带宽 max(H−1, ⌊4(n/100)^{2/9}⌋)；至少 60 个且至少 10×(带宽+1) 个日期；只剪掉首尾缺口，内部有缺口则为 N/A，不补值。月度只做描述统计，不给 HAC 或显著性。

层级：总体（按分区 Train / Validation / Test）、逐年、逐月。月份按信号日归属；分区边界（2024-01-01、2026-01-01）与月份对齐，一个月不会跨分区。

## 3. HTML 报告

新章节 “Factor Metrics · 完整因子评价体系” 放在因子定义之后，顺序固定：

1. **一、总体评价**：IC/RankIC 表、HAC 推断表（IC、RankIC、G0−G4）、样本与分组表、策略指标表；
2. **二、逐年评价**：每年的 IC/RankIC 均值、IR、胜率、RankIC HAC t 与区间、有效日、平均股票数、覆盖率；
3. **三、月度热力图**：12 项指标同时展示，没有切换器。依次为 RankIC 均值、IC 均值、RankIC IR、IC IR、RankIC 胜率、IC 胜率、G0−G4、G0、G4、单调性、覆盖率、平均股票数。2026 行在 Test 未评价时整行 N/A；
4. **四、G0–G4 分组明细**：逐年表（含 G0−G4 HAC t 与区间）和逐月表。

原逐年/逐月表放在章末的折叠区，数据同源。

**文件预算**：每项研究最多 100 个文件，这是安全边界，本轮没有放宽。真实研究原本已有 95–96 个文件，因此 12 张热力图只作交互图表，另生成一张“月度热力图总览”静态图（PNG/SVG/PDF，用于打印和下载），取代原来两张热力图的 6 个静态文件。指标数据只写一个 `data/metric_system.json`。合计文件数比之前少 2 个。

## 5. CMI 浮点噪声对排名与分组的影响（不做全局舍入）

`tools/rankflip_study.py` 在预发布 CMI 研究上比较系统 PKL 因子值与独立公式值。两者差 ≤ 2.3e-13，因子量级 600。

| 项目 | 结果 |
| --- | --- |
| 比较的因子格 | 6,518,750（1455 天） |
| 排序位置变化 | 284,209 格、1414 天，**全部发生在理论相等值组成的近似并列簇内**（相邻差 ≤ 1e-11×量级），簇外 0 |
| 分组成员变化 | 320 格（约 0.005%），150 天 |
| 每日 RankIC 最大差 | Train 7.8e-6，Validation 9.5e-6 |
| 每日分组收益最大差 | ≤ 1.2e-4（单日单组） |
| 分区均值影响 | RankIC ≤ 1.0e-7；G0、G4 ≤ 3.0e-7；G0−G4 ≤ 4.7e-7 |
| IR 影响 | RankIC ≤ 7.7e-7；G0−G4 ≤ 4.8e-5 |
| HAC 标准误影响 | ≤ 3.1e-8 |

结论：差异只来自理论相等值的先后顺序，对所有汇报指标的影响在第 4–5 位有效数字之后，不影响任何结论。按要求不改排名合同、不做全局舍入；独立核验时用“用系统 PKL 值重算”的方式区分统计错误和浮点噪声（`numcheck_study.py` 的 3b 项）。
