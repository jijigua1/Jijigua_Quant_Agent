# 因子指标合同 v1.0.0



所有数值由受审程序计算；qrtk原函数保持原字节。新聚合位于research_metrics.py。日期、代码、数据版本来自可信资源，参数在实验前冻结；T为观测日期位置，非已认证交易所日历。输出有限JSON或null、CSV空白；报告显示N/A，不用0冒充缺失。



| 指标 | 输入与方法 | 有效样本与时点 | 输出/限制 |

|---|---|---|---|

| IC / RankIC | qrtk.cross_sectional_corr，Pearson / Spearman平均并列秩 | 日期内共同有限因子及成熟open[T+1+H]/open[T+1]−1标签；至少10股票、两端非恒定；退出在当前分段内 | 每日序列；缺失或常数为NaN；相关非因果 |

| Mean / Std / IR / 正值比 | qrtk.ic_summary；等日期平均、样本std(ddof=1)、mean/std、>0比例 | 仅非空每日IC；n_dates，同时记录平均/最小有效股票数 | IR不年化；std零/不足2日期时IR为空；n_dates不是独立样本数 |

| HAC区间 | Bartlett Newey-West均值SE，gamma_k=n⁻¹Σe_t e_(t−k)；L=max(H−1,floor(4(n/100)^(2/9))) | 完整有限序列，n≥max(60,10(L+1))；split内purged日期网格 | 近似95%正态区间；未多重检验校正、不出星号；不满足为insufficient，零长期方差unsupported |

| 预测衰减 | H=1/3/5/10及实际H各自调用qrtk.evaluate_splits | 每个H独立生成下一观察开盘标签，并剔除段外退出 | IC及RankIC均值/有效日；不同H样本数可不同；不是因子值自相关 |

| Lag1/5/10值自相关 | 共同可观测股票的Pearson，逐日计算再等日期平均 | T及T−Lag都资格有效、有限，至少10共同股票，两端非恒定；当前T归属train/valid | 原始值相关、n_dates、mean_pairs；验证可使用早期训练的历史因子值，不使用未来值 |

| Lag1/5/10排序稳定性 | 同一共同股票的Spearman平均并列秩 | 与值相关相同 | 单独rank_n_dates与秩均值；不混同未来收益自相关 |

| 半窗稳定性 | 每段按purged序列位置分前/后半，用同ic_summary | 有效日期、样本std与均值分别保留 | 描述性、不据此优化窗口或宣称独立测试 |

| 因子方向一致性 | 预先固定方向+1；比较train/valid RankIC均值符号 | 均值可得才判断 | 描述符号，不据验证反转策略方向；零相关不能认定有效 |

| 分组毛收益/差/单调性 | qrtk既有等权分组；G0最高分，缺失标签排除；G0−末组；−Spearman(组序号,各组均值) | 每段成熟标签；每组输出H期mean/std/n | 非账户收益、未扣成本、非逐日净值；大组/小组权重均来自既有合同 |

| Top组排序换手代理 | qrtk.group_turnover：1−相邻Top组成员交集/当前Top组人数 | 观测行相邻；当前组空为NaN，首行NaN；暖机后首次有组且前组空按公式可为1 | 平均与每日CSV；因子排序/资格变化代理，不是实际组合换手、现金或交易成本 |

| 分布矩 | 训练+验证全部有限因子值：均值、样本std、Pandas无偏偏度/超额峰度 | 包含暖机矩形，但矩统计排除NaN/inf；同时记录有限格数 | 非时间独立样本；少样本、零方差等情况下NaN；不做尾部删改 |

| 分位数/覆盖/连续缺失 | 线性插值分位数；有限格数/全部可见矩形；逐股票最长连续NaN观测行 | PKL同一因子矩形截至valid结束；暖机缺失保留 | 覆盖并非可交易资格；缺失不能直接推断停牌 |

| 异常值率 | 每日有效股票稳健z=|x−median|/(1.4826 MAD)，阈值5 | MAD>0的可评价格为分母，独立记录extreme_assessable_cells | MAD零不可评估，不能冒充异常率0；阈值是固定诊断规则，不是收益优化 |

| 父子参数敏感性 | 同数据/H/分组/分段，比较真实父与子RankIC及样本数，独立保存参数表/图/CSV | 两实验必须同会话且指纹匹配；每次新计算新PKL | 暖机改变样本数；验证后调参属于探索，不是独立样本外 |



行业/市值中性化、行业/规模暴露、与历史因子相关、市场状态分组、独立测试、可交易账户指标需要额外经审输入/引擎。当前标为unsupported/BLOCKED，不造表格数值或账户图。daily65有效日期不足HAC准入，报告说明不足而不机械计算显著性。零方差时偏度/峰度及相关方向显示N/A/无法判断；不生成没有有效数值的预测、自相关或衰减图。图表进度分母来自实际可生成的图表集合。



核验：test_phase2c.py手算HAC、短样本/常数/非有限序列、独立numpy共同股票相关、未来截断不变；verify_real_studies.py独立标量因子/IC/秩/分组；verify_phase2c_metrics.py标准库独立偏度/峰度/分位数/MAD/连续缺失/自相关/成熟标签衰减和报告表格。结果见对应JSON证据。





补充验收：HAC的 n 为输入日期网格长度，n_valid 为有限观测日期数；推断表分别显示两者。只要存在缺失日期便拒绝HAC，不能删去缺失后伪装连续序列。IC核心表仍使用有效日期数。
