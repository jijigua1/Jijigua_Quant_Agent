## 不开放的候选功能

1. `normalize_daily_bars` 保留负成交量/金额，未充分阻断不可信输入；新增确定性测试记录该行为。主 Agent 不调用此函数，自己的读取门禁拒绝负成交量。
2. 分钟标准化/聚合虽通过合成测试，但真实分钟时间戳、网格、竞价窗口及历史时段合同未取得；异常网格和时间窗仍需要补充边界验收。本轮不登记分钟 Tool。
3. 参考账户支持 T+1、费用、拒单、现金/持仓/NAV 对账，独立手算案例已覆盖。但缺公司行动、退市、完整历史涨跌停/板块规则及市场冲击合同；信号转订单维护的是意图持仓，不能当成交后持仓及重试政策。没有开放真实账户回测 Tool。
4. `reveal_test`、任意函数注册、引擎动态注册、候选 Runtime 的动态调度和任意 artifact_dir 均不对模型开放。测试段持续封存；新参数实验保持探索性，不能通过反复创建任务声称独立验证。
   这里封存的是计算输出，不是原始数据的盲测隔离；原有data_query保留获批快照读取，尚无全系统独立holdout和一次性解封机制。
5. qrtk 的底层相关函数自身不是全输入安全边界；原函数对 infinity/参数类型的保护不足。主入口执行封闭参数与有限值校验，不向模型暴露底层函数。
