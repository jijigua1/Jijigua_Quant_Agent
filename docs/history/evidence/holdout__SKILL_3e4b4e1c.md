# Mock Research Skill

## 适用范围

固定六行模拟量价数据的协议回归。它不检验真实金融假设，不包含真实收益、交易或行情文件。

## 方法

1. 提出可检验的窗口敏感性假设，并记录选择下一步的理由。
2. 用 query_mock_data 确認唯一批准的模拟资源，保存数据指纹。
3. 用 compute_mock_factor 比较3期和5期指标，每次参数修改有理由。
4. 用原样工具结果作证据；模型摘要必须标明模拟性质。
5. 完成两次对照即可结束。预算/权限/工具错误立即停止，不能通过修改权限或换工具绕过。

## 验收

- 输出标记 synthetic，包含两个 factor 实验及其参数、数据/实现指纹。
- 原始结果与摘要分开。没有实际研究有效性、回测绩效或服务器能力断言。
- 固定示例见 example.json；自动回归见 tests/test_workflow.py。

资源声明中的 CPU/内存/PID 不代表本地已实施 OS 硬配额。本 Skill 不创建作业、文件或子进程；程序调用预算另行强制。
