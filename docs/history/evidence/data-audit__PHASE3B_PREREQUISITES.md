# Phase 3-B 正式回测准入前置项

Phase 3-A **没有批准任何真实账户回测数据**。下一阶段可以继续独立验证回测引擎的确定性账本，用合成案例审手续费、印花税、现金、持仓、拒单和下一日执行；**待独立发布 Train/Validation 快照后**，方可用六个原始字段做注明局限的探索性因子计算、数据质量过滤与接口测试。不能从因子分组毛收益推导账户净值、Sharpe 或正式策略有效性。

正式回测的数据闸门至少要求：

1. **股票池时点**：逐日上市、退市、暂停上市、证券身份及交易所范围；解释并屏蔽已发现的 1,228 个上市前单元及固定轴缺失的新股。
2. **可交易状态**：逐日可买/可卖、交易所停复牌、ST、涨跌停价格及拒单；当前冻结/错误状态字段不得复用。涨跌停须来自可信规则和历史板块/ST状态，最好有交易所记录交叉核验。
3. **公司行动及价格单位**：分红、送配、拆合、除权日、现金与股数调整；复权与原始成交价、执行股数的关系必须可核；旧新 `close_adj` 历史重写后需稳定快照及版本化解释。
4. **时间信息**：T 日行情、基本面、市值、行业、公告及公司行动的实际公布/可获取时间；`next_open` 等未来列只进入隔离的标签/执行侧。标签成熟、purge/embargo 依据真实交易日历逐任务证明。
5. **价格与费用**：下一交易日可成交开盘价或可靠逐笔/分钟约束、滑点、手续费、印花税、最小手数、涨跌停/停牌拒单、卖出失败后持仓延续；对真实 A 股股数与复权份额明确区分。
6. **样本与对照**：动态沪深/BJ 范围、退市样本留存、基准及成分历史；不能因为当前固定轴覆盖 5,427 只就宣称完整全市场。EOD 两份相同文件不可作独立数据源交叉认证。
7. **持久 Holdout 边界**：研究身份无 2026 文件/FD 权限；训练验证只有独立发布资源；独立评估器的权限、使用次数、冻结实验哈希、审计和泄漏旁路检查合格。主 Agent v0.6.8 本轮不变；不能以本目录 `SplitReader` 原型替代部署验收。
8. **确定性引擎验收**：用可手算公司行动、涨跌停、停牌、费用、现金/持仓/NAV 对账案例，与独立账本交叉验证，明确每一执行价时间。只有数据合同和引擎合同同时通过，才可注册正式回测 Tool。

推荐最小推进顺序：先发布已获授权的 Train/Validation 六字段小切片与真正隔离的 Holdout；补逐日上市和真实交易状态；验证公司行动与复权版本；最后用合成成交账本核对候选回测引擎。每一步都输出独立证据和失败状态。**本文件列的是准入缺口，不是 Phase 3-B 实施授权；本次未启动 3-B。**
