# 论文研究可靠性

## AI主张与程序事实

`understanding.py`要求每项研究主张带段落ID与至少可定位引文。`evidence.py`建立分段检索，程序再次逐字核验来源。主张分为PAPER、DERIVED、REPLICATION_CHOICE、UNKNOWN、UNVERIFIED、CONFLICT；“模型说原文有”本身不是证据。

版面解析的公式与AI读法不一致时，`reconcile.py`可有限调查：检索、邻段、整页原始文本层。保存的页面截图供人看，纯文本DeepSeek看不到图像；不能宣称完成视觉读公式。不能解析的数学区域应标为提取/解析缺口，而不是断言论文没有定义。

## 参数、公式和资产

- 自由参数必须来自可定位原文、明确复现选择或用户原话，三类分别记录。RSI“X days”不能擅自绑定惯例14；用户输入X=14后应标为用户选择。
- 数学斜体引文先NFKC归一化核对，仍保留原文。价格比值的累计回看与单期收益滞后不能混用。
- 点名Alpha#12不能因检索候选含Alpha#1就换研究对象。编号、标题和来源一致性必须进入缓存/选择检查。
- 论文只研究指数、期权或期货时，不自动代换A股。资产替代与频率换算需要明确确认，报告记录偏离原文。
- GMI等隐含状态算法不能用可解析的近似公式冒充原定义。缺少算子应阻断或生成待审核方案。

## 审核与执行

DSL与可信IR只接受封闭算子、合法窗口、完整暖机和过去信息。候选源码先按AST规则检查负向shift、中心窗口、非法导入、动态执行、未知文件/网络、缺失值填充等，再确认精确SHA并用独立期望值测试。AST检查不是恶意Python沙箱，执行路径和IR不能混为一谈。

## 重复运行与失败分类

固定模型温度不能保证研究语义相同。A/B框架比较因子身份、公式、参数、资产决定与准入状态，不只比较措辞；开发集和已曝光集不再称盲测。每轮记录源码、论文SHA、Provider、用量、耗时和失败类别。

JSON括号修复只调整结构，不修改字符串；修复后仍须Schema与数学/引文核验。截断应有界重答，不无限修复。HTTP错误、预算耗尽、程序解析不支持、数据缺失、原文歧义与模型误读应分别记录。真实回归不足时标UNVERIFIED，不把正确阻断与工具能力缺失都算成功。

相关历史材料见[事故目录](../history/INCIDENTS.md)。论文方法与结果不是同一物：不能把作者汇报的最佳样本绩效作为本系统参数或已复现证据。
