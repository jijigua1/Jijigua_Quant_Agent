# 数学、时间与统计合同

## 1. 信号与成熟标签

令交易日索引为有序观察序列`t`，因子`f[t,i]`在T日收盘后可得，只依赖T日及以前。默认执行延迟`L=1`，持有`H`个开盘区间，标签为

$$y_{t,i}^{(H,L)}=\frac{O_{t+L+H,i}}{O_{t+L,i}}-1.$$

`qrtk.factor_eval.forward_returns`按交易日位置shift，而不是自然日加法；退出时点已发生才是成熟标签。例：6个观察日的开盘价为10、11、12、13、14、15，T=首日、L=1、H=2，则入场11、退出13，标签13/11−1≈18.18%。这只是价格描述，未模拟成交。

Train末端退出跨Validation的标签剔除；Validation末端不能读取Test补全。Validation可使用已允许Train历史暖机，但标签不得逆流。累计暖机由嵌套delay/returns/rolling递归推导，不以一个固定20日替代所有公式。purge取决于信号、执行延迟与预测期；embargo需由具体实验合同声明，不假设固定天数适合所有策略。

五日反转例：`f[t,i]=−(C[t,i]/C[t−5,i]−1)`。20日动量则为正的20日价格变化，二者不是模型可自行互换的替代方案。

## 2. IC与RankIC

同一日取因子与成熟标签均有限、符合当日允许股票池的共同集合`S_t`：

$$IC_t=\frac{\sum_{i\in S_t}(f_{t,i}-\bar f_t)(y_{t,i}-\bar y_t)}{\sqrt{\sum(f_{t,i}-\bar f_t)^2\sum(y_{t,i}-\bar y_t)^2}}.$$

RankIC对两组数据先分别取平均并列秩再用同一公式。有效对数不足或任一截面常数时为NaN，不是0。实现：`qrtk/factor_eval.py::cross_sectional_corr`。例如f=(1,2,3)、y=(3,2,1)，二者IC和RankIC都为−1。反向定义需事前固定，不能看完Test后翻转。

全区间均值是有效日的均值；样本标准差使用ddof=1；`ICIR=mean(IC)/std(IC)`，**未年化**。正值占比/Win Rate为有效日中严格>0的比例；零值不计正，缺失不作为0。只有一个有效日无法计算样本Std/IR。

## 3. HAC / Newey–West

令x为日度IC、RankIC或理论分组差。对剪去结构性首尾缺失后的完整序列，

$$\hat\gamma_k=\frac1n\sum_{t=k+1}^{n}(x_t-\bar x)(x_{t-k}-\bar x),$$
$$\hat v=\hat\gamma_0+2\sum_{k=1}^{K}(1-k/(K+1))\hat\gamma_k,\quad SE(\bar x)=\sqrt{\hat v/n}.$$

带宽`K=max(H−1,floor(4(n/100)^(2/9)))`。合同要求`n≥60`且`n≥10(K+1)`；内部缺失不压缩成连续日、不补值，返回insufficient。长期方差近零/不可用返回unsupported。近似`t=mean/SE`，双侧p用渐近正态尾部，95%区间`mean ± 1.95996398454 SE`，不是精确有限样本Student t检验。

实现：`research_metrics.hac_mean`、`factor_evaluation.inference`、`metric_system._describe`。独立工具`tools/numcheck_metrics.py`从日度证据重建。月度通常不足60日，因此只提供描述统计，不能机械输出显著性星号。HAC处理序列相关的假设，不消除验证集反复调参、多重检验或原始价格公司行动偏差。

## 4. 分组及方向

实现`qrtk.factor_eval.assign_groups`：在事前方向乘因子后降序排名，G0最好，G4最低（五组）；并列按原代码列次序打破以保持确定性。每组标签均值在有效且有标签成员中等权计算，另报覆盖。G0−G4是两组未来毛收益差，不是可同时成交的组合利润。

例：两组各两个股票，最高组未来收益(2%,4%)、最低组(−1%,1%)，均值3%和0%，理论差3%。这并不包含现金闲置、拒单、交易费用、卖出失败、公司行动或融资约束。

单调性是`−Spearman(组序号,组收益)`：高分组收益更高时为正。信号排名变动、组成员换手代理和实际账户换手是不同变量。不能从排序变化直接生成交易成本。

## 5. 年、月、自相关与衰减

年/月归属使用信号日期；每年每月从实际日度序列独立聚合，不拆总均值。热力图NaN显示N/A，以0为中心的对称色阶只用于有正负意义的指标。覆盖率、股票数应使用适合其取值范围的色标。

因子Lag-k自相关：在t与t−k日共同可观测股票上计算横截面Pearson，再在时间上汇总；Rank Autocorrelation则对共同集合平均秩相关。它不是收益自相关。预测衰减是在不同H成熟标签下重新计算IC/RankIC，不是因子持久性。滚动IC按声明20/60观察日计算；累计IC只是和，不是NAV。分区累计展示可以连续，但缺失实际数据不能插值或延伸。

## 6. 正式账户指标的前置条件

年化收益、波动、Sharpe、最大回撤、Calmar需来自已验收的连续账户收益/净值。Sharpe通常为`mean(r−rf)/std(r−rf)*sqrt(A)`，回撤为`NAV/running_max(NAV)−1`，年化与频率A必须声明。本项目当前不能以重叠未来分组标签套用这些公式并声称账户回测合格。

原始未复权价格收益不等于总收益；价格存在不等于可成交；相关性不等于因果机制。研究结论必须同时披露统计与数据资格。
