# 开发者指南

## 从代码入口开始

安装保留Python发行名`wty-research-agent`及`qra`入口；项目与仓库名为Jijigua_Quant_Agent，不能为了命名整齐破坏已有导入。核心包为research_agent、paper_agent、paper_research、rolling_test及qrtk/qrtk_skills。

## 扩展Tool

参照`tools.py`与`paper_tools.py`，定义封闭输入/输出Schema、固定handler、实现版本、风险/资源声明及结果验收。将其绑定Skill并更新可信内容指纹；Policy、Skill与任务授权交集决定是否可执行。拒绝额外参数、任意路径、Shell和模型自授予权限。新增Tool前先检查现有helper是否已支持；本地会话授权不能冒充独立Test许可。

## 扩展DSL或可信IR

DSL节点必须只引用之前节点，窗口/深度/节点数有界；量纲、零分母、缺失及累计暖机要检查。IR扩展同时更新语法、字段依赖、warmup、LaTeX渲染、参考执行器、向量化执行器、独立测试及独立评估器白名单。未来扰动截断测试证明T日输出不依赖T后数据。数学意义改变须升级语义版本，未知版本拒绝；旧冻结定义不能改SHA。

## 增加指标

优先复用已有日度IC/RankIC与分组证据，不重复读行情。写明输入、有效样本、缺失、时点、单位、分组方向和统计限制。手算或独立实现作为预期值；均值相同不是逐格正确的证据。HAC需检查内部缺失、重叠标签和样本门槛，月度不应因产品想要显著性而放宽准入。

## PDF与模型

解析器改动需要页码/bbox和引文测试；公式无法抽取与原文未定义分开。LLM只提出主张，程序核验引文、参数和资产。请求按UTF-8字节预算，不按字符数假设64KB安全。JSON修复不能修改字符串内容，错误和重试计入预算。

## 报告与缓存

表格和图共用保存证据，数值不从生成摘要提取。Test缺失保留栏位和原因；Test回执完成后同study追加revision。只读工具不得暗中重评Test。缓存绑定数据、定义、算法语义与评价合同；源码优化不应改变冻结语义，改变时新实验。

## 测试策略

- `tests/conftest.py`禁网络；需要真实API的工具不进pytest默认路线。
- 新逻辑至少一个正常例和一个失败/边界例，独立数值测试不导入被测公式。
- 公共CI明确Windows/Linux/macOS条件，不能把Windows缺grp写成产品数学失败。
- 为审阅留存失败原始结果，不用改断言掩盖不兼容。
- 修改公开副本后更新转换/哈希清单，运行release_audit、链接检查与包构建。

本轮只对公开归档做必要脱敏、打包、文档和测试修正；没有替Claude修复活跃研发代码。后续内部同步仍须完整验收与单独公开审批。
